# 真汇算宣传视频制作规格

## Stage 0 · 产品简报

### 一句话定位

真汇算是一款面向外贸和日常金额换算的极简浏览器扩展：不选换算方向、不点“换算”，直接在任意币种金额框输入，其余币种立即联动。

### 核心受众

- 需要频繁核算多币种报价、采购款与回款金额的外贸从业者。
- 需要在人民币、港币、美元、越南盾等币种之间快速心算校验的人。
- 不想反复选择“从什么币换到什么币”的 Chrome / Edge 用户。

### 只展示已验证能力

- 任意一个已显示币种都可以成为输入源。
- 输入时自动联动其他币种，无额外换算按钮。
- 识别金额中的常见千分符与本地化分隔格式，例如 `1,000`、`1.234,56`、`1 234 567,89`、`26.252.670`。
- 可同时显示 2–8 个币种，并从约 165 种币种中配置。
- 自动按浏览器语言显示简体中文、繁体中文、英语或越南语。
- 汇率来自 ExchangeRate-API；视频中的数值是确定性演示数据，不构成报价或投资建议。

### 禁止口径

- 不提、不演示科学计数法。
- 不声称银行级、交易级、零延迟或绝对实时。
- 不虚构真实竞品界面、名称或价格。
- 不把自愿赞助描述为购买、订阅或功能解锁。

### 创作决策

| 项目 | 决策 |
|---|---|
| 模式 | 自主自由创作 |
| 画幅 | 1920×1080，16:9 |
| 帧率 | 30fps |
| 主片时长 | 约 27 秒 / 810 帧 |
| 语言版本 | 简体中文主版、英语国际版；同一时间线参数化 |
| 声音 | 无旁白；BGM + 轻量 UI / 输入 / 转场音效 |
| 交付 | 每种语言输出 BGM 版；简体中文另输出无 BGM 版作为强制双版本 |
| 产品素材 | 真实扩展页面截图与真实 DOM 元素切片 |
| 数据 | 使用冻结的演示汇率与金额，确保逐帧确定性 |
| 商店用途 | 作为 YouTube 宣传视频源文件；Chrome / Edge 后台填写 YouTube 链接 |

## Stage 1 · 视觉方向

### 方向名称：精准流动 Precision Current

用产品原生界面建立可信度，把“数字在多币种之间流动”做成唯一视觉隐喻。画面干净、迅速、有专业工具感，但不做金融交易终端的压迫感。

### 设计令牌

| 类型 | 值 |
|---|---|
| 主色 | `#1265E9` |
| 深主色 | `#0759D8` |
| 深色舞台 | `#071426` / `#0B1F3A` |

| 数字 | tabular-nums + lining-nums |
| 圆角 | UI 10–18px；舞台卡 28–44px |
| 阴影 | 蓝黑色低透明长阴影，不使用彩色霓虹 |

### 动效语法

- 主要动作单向、短促、落定明确；产品卡只用一次完整建立镜头。
- 数字更新是主角：输入字符与其他金额变化同拍发生。
- 不使用夸张卡通弹跳；物理落位允许约 1.02 的轻微过冲。
- 一个镜头只承担一个核心信息，主信息落定后至少保留 30 帧。
- 转场优先使用产品里的输入框、分隔线和蓝色焦点框作为接力元素。

### 字幕语气

- 简体中文：短句、直接、口语化。
- 英语：短词组，不做中文逐字翻译。
- 每屏最多一个主标题和一个辅助说明；结尾口号不与中段重复。

### Styleframe

三张 1920×1080 纯 HTML/CSS 关键帧位于 `video/styleframe/`：

1. 问题钩子：抽象流程被删减，不呈现具体竞品。
2. 产品立传：真实插件界面成为唯一主角。
3. 功能收束：千分符、多币种、自动语言形成一组证据。

## Stage 2–3 · 镜头选择与分镜

### 镜头库映射

以下 `style-key` 均已在 `gallery/api/library.json` 中核对；实现前已完整阅读对应卡片与参考 TSX。

| 片段 | 卡片 / style-key | 本片适配 |
|---|---|---|
| 产品立传 | `spotlight-hero-card` | 主角从单张功能卡改为完整插件窗口；保留聚光锁定、缓慢推进、一次完整动作弧和高清特写原则。 |
| 输入触发 | `input-trigger-moves` / `cursor-performance` | 从“点击按钮触发”改为“点击金额框并输入触发”；保留光标曲线路径、点击同帧推近、停留与缓退。 |
| 结果落定 | `row-embed` | 结果行不虚构新增，而是在真实更新后以底边蓝色接缝逐条确认；保留真实纹理切片、错峰落位和一次性接缝。 |
| 多状态证据 | `panel-grid-moves` / `comic-panel-split` | 同一插件的换算、设置、多语言三个真实状态组成三机位斜格；只在全片使用一次分格。 |
| 语义接缝 | `shot-transitions` / `mask-wipe` | 放大真实金额输入行，从 CNY 输入状态穿到 VND 输入状态；窗几何和窗内景共用一个进度。 |
| 品牌收尾 | `ui-to-brand-morph` / `input-morph-assemble` | 金额输入框缩成蓝色图标底板，白色输入线段重排成双向箭头，随后落定字标与平台信息。 |

### 能量骨架

对 27 秒单功能工具片采用 `promo-energy-arc` 的短片变体：品牌开场与主角立传合并；功能爬升只保留两个真实输入演示；分格证据是峰值；UI 变品牌完成收场。没有额外呼吸字卡，避免重复口号。

| 段位 | 帧 | 时长 | 能量 | 职责 |

| 问题钩子 | 0–83 | 2.8s | 低→中 | 抽象删去“选方向、点换算”的多余步骤，不指向具体竞品。 |
| 单主角立传 | 84–203 | 4.0s | 中 | 真实插件窗口被聚光锁定，建立产品和四币种同屏概念。 |

| VND 反向输入 | 378–515 | 4.6s | 中高 | 金额行穿窗，直接粘贴 `26.252.670`；证明任意币种都能成为入口。 |

## 数据与合规备注

- 宣传片中的金额只用于解释产品交互，不展示买入价、卖出价或交易建议。
- 汇率更新时间和来源须在真实 UI 中可见，不用字幕放大成营销承诺。
- Chrome / Edge 商店版本避免“实时汇率”绝对化，统一使用“在线汇率”“自动更新”或“即时换算结果”。
