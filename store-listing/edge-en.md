## Short description

Enter an amount in any currency field. All others update instantly, with smart thousands-separator parsing.

## Description

Most currency tools make you choose a source, choose a target, and click Convert. Zhen Hui Suan turns that flow into one linked table: every visible currency is an input, and changing any row updates all the others.

It starts with CNY, HKD, USD, and VND—useful for cross-border purchasing, quotations, travel, and everyday comparisons. In Settings, you can show 2–8 currencies and freely add, remove, replace, or reorder about 165 currencies from the exchange-rate source.

Pasted amounts work without cleanup. `1,000` is read as 1000. The parser also supports `1.234,56`, `1 234 567,89`, `26.252.670`, full-width digits, and common currency symbols.

The interface automatically follows the browser language in Simplified Chinese, Traditional Chinese, English, and Vietnamese. Currency settings, the last input, and the latest rate cache stay in the browser. There are no ads, accounts, analytics, web-page access, or browsing-history access.

Rates come from the free ExchangeRate-API Open Access endpoint. Calculations update instantly after typing, while the source provides the latest daily reference rates—not tick-by-tick market quotes. Bank, payment-platform, and customs settlement rates may differ.

The project is fully open source under the MIT License. Sponsorship in Settings is optional and never unlocks or limits features.

## Key features

- Enter an amount in any currency row
- CNY, HKD, USD, and VND by default
- Show 2–8 selected currencies
- About 165 currencies
- Smart thousands and decimal separator parsing
- Four automatic interface languages
- Local settings and rate cache
- No ads, tracking, or page access
