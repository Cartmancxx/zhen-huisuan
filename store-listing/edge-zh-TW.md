# Microsoft Edge Add-ons 上架資料（繁體中文）

## 簡短說明

不用選擇換算方向：在任意貨幣欄輸入，其他金額立即連動。支援千分位、2–8 種自選貨幣與自動語言。

## 詳細說明

真匯算把多幣種換算放在同一張連動表中。每個顯示中的貨幣欄都能直接輸入，改變任何一欄，其他金額會立即更新，不需要選擇來源、目標或按轉換按鈕。

預設人民幣、港幣、美元和越南盾，也可同時顯示 2–8 種自選貨幣。`1,000` 會辨識為 1000，並支援多種千分位、小數、全形數字與貼上格式。

介面會自動跟隨瀏覽器語言，支援簡體中文、繁體中文、English 和 Tiếng Việt。設定與匯率快取只保存在本機；不讀取網頁、瀏覽紀錄、Cookie 或剪貼簿。

匯率資料為最新每日參考匯率，並非逐秒交易行情。專案完整開源；贊助完全自願，不會影響任何功能。
