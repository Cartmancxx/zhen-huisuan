# 宣传视频上传 YouTube

Chrome Web Store 和 Microsoft Edge Add-ons 的“宣传视频”字段都填写 YouTube URL，不能直接上传 MP4。

- 文件：`store-assets/video/zh-CN/zhen-huisuan-promo-zh.mp4`
- 缩略图：`store-assets/video/zh-CN/youtube-thumbnail-1280x720.png`

- 说明：

```text

真汇算让每个货币框都能直接输入：输入 1,000，会自动识别为 1000，其他货币金额立即联动。默认人民币、港币、美元、越南盾；可同时显示 2–8 种货币，并支持约 165 种货币。
```

## 上传设置

- 可见性：先设“不公开”即可，不能设“私享”；准备正式发布时也可改为“公开”
- 观众：不是专为儿童制作
- 允许嵌入：开启
- 广告：关闭，Microsoft Edge 明确要求宣传视频不带广告
- 字幕：视频本身已有完整画面文字，可选填
- 语言：中文视频选“中文（简体）”，英文视频选“English”
